# 禁欲打卡 v2 · iPhone 网页 App

更新内容：修复手机月历错位；任意过去日期补记、编辑或清除；做爱 💞 / 自慰 ✋ 分别记次数；7 天、30 天、本月和全部看板，含成功率、记录覆盖率、两类次数、六个月趋势和可编辑记录列表。

## 更新现有 GitHub Pages

1. 更新前，在旧页面点“导出备份”，把 JSON 保存到 iCloud Drive。
2. 解压本包，将其中所有文件上传到**原 GitHub 仓库原位置**，同名文件选择替换。请上传文件本身，别再套一层文件夹。
3. 等待仓库 Actions 中 Pages 部署完成，然后打开原网址。确认页面左上显示 v2。
4. 若桌面 App 仍是旧版，联网退出再打开；看到刷新提示就点刷新。也可先在 Safari 中打开原网址，刷新后再回桌面 App。
5. 若仍看到旧版，在 Safari 中打开原网址并加 `?v=2`（已有参数就加 `&v=2`）。不要清除 Safari 网站数据来更新，否则可能丢记录。

代码更新不能保证已部署的 GitHub 页面立即刷新，需要替换仓库文件并完成部署。本包不自动访问你的 GitHub 账号。

## 记录操作

- 今天：点“记录今天”，选择成功、未成功或未记录，保存。
- 过去日期：直接点月历日期，或点“选择日期补记”并改日期；禁止记录未来。
- 未成功时：可分别填写做爱、自慰的射精次数，同一天支持两类各多次。未达成目标但未射精也可保留 0 次。
- “未记录”会清除该日期的每日记录；旧版重置历史作为只读档案保留。
- 可自由补记起始日前的日期，追踪起始日随之提前。

## 统计口径

- 当前连续：逐日有明确成功记录才累积。今天未记录时计算至昨天；今天未成功归零。过去未记录日期中断连续。
- 最长连续：所有明确成功记录中最长相邻日期序列。
- 成功率：成功天数 / 所选范围内已到来的追踪日数；未记录日计入分母。
- 记录覆盖率：（成功天数 + 未成功天数）/ 同一分母。
- 次数：做爱与自慰分别统计，不是天数。
- 六个月趋势独立显示各月成功率；尚未开始追踪的月份显示“—”。

## 旧记录与备份

保留原版存储键 `abstinence_checkin_state_v1`、数据库 `AbstinenceCheckinDB` 和对象存储 `state`。旧版 checkins 迁为成功；resets 迁为未成功并保留备注。两者同一天时以重置为准。旧版未记射精方式的重置不猜测类型、次数；可手动补充。

旧版按起始日自动累计的天数，没有逐日成功记录的部分不会凭空迁成成功；请在日历里补记真实状态。

支持导入旧版/新版 JSON；导入前校验，自动保存导入前快照以供撤销。备注作为纯文本显示。导出所有每日记录、分类、次数、备注、旧重置历史和设置。

数据仅保存在当前设备的网站存储中（localStorage + IndexedDB）。更新必须沿用原域名和原路径；iOS 不同打开方式可能使用不同存储空间，切换 Safari 与主屏幕 App 若看不到记录可用 JSON 导入。清除网站数据、换机或系统回收站点存储可能丢记录；两份本地存储不等于云同步，请定期导出到 iCloud Drive。存储失败会在顶部提示。

## 首次安装

将全部文件部署到 HTTPS 静态站点。iPhone Safari 打开网址 → 分享 → 添加到主屏幕。首次联网成功加载后可离线打开。程序与图标不包含你的个人打卡记录。

无需 Xcode 或第三方前端依赖。
